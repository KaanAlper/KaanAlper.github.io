Privacy Policy

Last updated: September 22, 2026

This Privacy Policy applies to the ByteForge desktop application and describes how your information is handled.

1. Data We Collect

ByteForge does not collect, transmit, or store any personal telemetry, usage data, or analytics on external servers. Static binary analysis, disassembly and memory inspection all happen entirely on your local machine.

2. Files & Process Access

  • ByteForge reads the binary files (APK, ELF, PE and similar) and the running process memory that you explicitly open or attach to. It never accesses files or processes outside what you point it at.
  • Any patches or memory edits you make are written only to the file or process you are working with — nothing is uploaded anywhere.

3. Local Storage

Application settings, recent-file history and workspace state are stored locally on your disk. No account or cloud sync is required or used to run the application.

4. Network Access

ByteForge is offline-first: it does not require an internet connection to inspect or patch the files and processes you open. The only outbound request it may make is an optional check for newer releases on GitHub.

5. Legal & Responsible Use

ByteForge is a research and engineering tool. You are responsible for ensuring your use of its reverse engineering, disassembly and memory-editing features complies with applicable law and the terms of any software you analyze.

6. Contact

If you have any questions about this Privacy Policy, you can check the GitHub repository or contact the developer at kaanalperkaraaslan@gmail.com.
